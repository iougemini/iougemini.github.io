GitHub 文件加速

Release / Archive / Raw / Gist 文件下载加速：粘贴 GitHub 文件链接，一键生成加速下载地址，无需登录、无需安装。

Cloudflare CDN 加速 Release · Archive · Raw 文件跳转 JsDelivr 无需注册 · 纯公益

输入链接 · 一键加速

键入 Github 文件链接，点击下载即可在新窗口打开加速地址

GitHub 文件链接

支持 release / archive / blob / raw

使用说明

  • GitHub文件链接带不带协议头都可以，支持release、archive以及文件，右键复制出来的链接都是符合标准的，更多用法、clone加速请参考这篇文章。
  • release、archive使用cf加速，文件会跳转至JsDelivr
  • 注意，不支持项目文件夹

链接示例

EG
分支源码 https://github.com/hunshcn/project/archive/master.zip
release源码 https://github.com/hunshcn/project/archive/v0.1.0.tar.gz
release文件 https://github.com/hunshcn/project/releases/download/v0.1.0/example.zip
分支文件 https://github.com/hunshcn/project/blob/master/filename
