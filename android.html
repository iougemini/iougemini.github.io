自建 KMS 激活服务器

无需 Root 的安卓手机、Linux / Windows 服务器，都可以搭建自己的 KMS 激活服务器。

安卓方案 Linux 方案 Windows 方案
1

下载并安装安卓版 KMS 服务器软件

下载安卓版 KMS 服务器 (APK) 本站直接下载
2

连接同一网络并启动软件

确保手机与需要激活的电脑连接同一 WIFI 网络（或在同一局域网内），然后启动软件。

3

启动服务器并记录 IP 地址

点击软件中的「启动服务器」，查看软件内显示的「IP 地址」（形如 192.168.1.XXX）。

4

在电脑上执行激活命令

注意将命令中的 IP 地址替换为上一步软件内显示的地址。

Windows 激活 · 命令提示符（管理员）
C:\> slmgr /skms 192.168.1.XXX && slmgr /ato
Office 激活 · 进入 OSPP.VBS 目录后执行
C:\> cscript ospp.vbs /sethst:192.168.1.XXX && cscript ospp.vbs /act

进阶玩法

  • VOL 版系统安装完成后会自动搜索局域网内的 KMS 服务器并自动激活（已装的未激活系统会在 2 小时内陆续自动激活），无需任何操作。
  • 懂得内网穿透或动态解析（需开放 1688 端口），你的手机同样可以为全球提供 KMS 激活服务。
  • 没有 WIFI 时，可在软件设置内使用「WIFI 热点」「USB 系绳」等方式提供激活服务。
  • Linux / Windows 系统自建 KMS 服务器请访问：github.com/Mr-xn/kms-server-deploy
