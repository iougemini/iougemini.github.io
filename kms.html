1激活 Windows

右键点击电脑左下角的 Windows 徽标，选择「命令提示符（管理员）」或「Windows PowerShell（管理员）」。本站命令已同时兼容 CMD 与 PowerShell，任选其一执行即可（推荐 CMD）。

C:\>slmgr /skms s.ikms.eu.org && slmgr /ato

在弹出的窗口中点击鼠标右键粘贴命令，并按回车键（Enter）执行。⚠️ 必须使用管理员权限运行，否则会提示权限不足。

命令执行完毕会自动弹窗：显示「成功地完成了…」即为成功；如果弹窗报错并显示 0x 开头的代码，把它记下来，到下方「常见报错速查」对号入座即可。

最后在「设置 → 系统 → 激活」中确认显示「已激活」即为最终成功。

2激活 Office

Office 只有批量授权（Volume License）版本才支持 KMS 激活，零售版不支持——需要先通过「Office 安装」功能重新安装批量授权版本后激活。

C:\>cscript ospp.vbs /sethst:s.ikms.eu.org && cscript ospp.vbs /act

如果找不到 ospp.vbs 文件（常见于组件不完整或非默认安装路径），可直接联网完成激活，无需先定位该文件。

执行后看弹窗：出现「LICENSE STATUS: —LICENSED—」或「激活成功」即成功。

最终确认：打开任一 Office 组件（如 Word）→「文件」→「账户」，看到「产品已激活」即成功。

60xC004F074 / 0x80080005 / 0x8007000D 报错

原因一：网络不通，无法联系 KMS 服务器（0xC004F074 最常见的原因）。请更换网络（如手机热点、代理）后重试，或在 PowerShell 中确认服务器可连通：

PowerShellTest-NetConnection s.ikms.eu.org -Port 1688

原因二：曾使用过同类激活工具，导致系统激活组件 SppExtComObj.exe 被劫持（常见报错 0x80080005 / 0x8007000D，也会导致「设置-激活」页面打不开，见第 8 条）。执行下方修复命令，完成后重启电脑再试：

C:\>reg delete "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\SppExtComObj.exe" /f & net stop sppsvc & net start sppsvc

若换网络无效：请检查电脑时间是否准确（时间偏差过大也会导致激活失败）。打开「日期和时间」设置，开启「自动设置时间」后重试。

70x8007007B 格式错误

原因：KMS 服务器地址或产品名称格式不规范（如误含 http://、空格、中文或多余字符），系统提示「文件名、目录名或卷标语法不正确」。

解决办法：先用 slmgr /skms 重新设置服务器，只填主机名或「主机名:端口」（如 slmgr /skms s.ikms.eu.org），再依次执行 /ipk、/ato。

8设置里的「激活」页面打不开 / 一直空白或转圈

如果您点开「设置」>「系统」>「激活」时，页面一直空白、转圈加载或直接闪退，这通常也是同类激活工具劫持 SppExtComObj.exe 导致的（激活页面依赖该系统组件，被劫持后就无法正常显示）。

解决办法：执行 第 6 条 中的修复命令清除劫持，然后重启电脑，激活页面即可正常打开。

9异常排查

通过 CMD 或 PowerShell 执行以下命令可以查看激活日志，排查错误信息：

C:\>cscript //nologo slmgr.vbs /dlv > %TEMP%\activ.log 2>&1 & notepad %TEMP%\activ.log

查看技巧：在输出结果里找 0x 开头的错误码（如 0xC004F074），回到上方对应条目即可对号入座；激活失败时系统弹出的报错窗口里也会显示同样的 0x 代码。

注意：请完整复制整条命令（显示换行不影响执行），不要手工拆行。

10Windows 版本切换

同一代 Windows 系统可以无损切换版本（例如从 Win11 家庭版升级至专业版），无需重装系统。

第一步：从首页选择并复制密钥

在首页选择你的系统版本与目标产品版本（例如 Windows 11 → 专业版），选择完成后在「激活命令」卡片中点击【仅复制密钥】按钮。

第二步：输入密钥进行升级

复制密钥后，依次打开电脑的「设置」>「系统」>「激活」>「更改产品密钥」，输入刚才复制的密钥即可开始升级。

如果输入专业版密钥提示「产品密钥无效 (0xc004f050)」怎么办？

这是 Windows 的常见切换限制。请改用专业工作站版或企业版密钥重新尝试，同样可以顺利无损切换。

参考微软教程： Windows 版本升级
